# 入力するシート

board が読むスプレッドシートの形を定める。テンプレートは `board/templates/` にあり、Drive では
これを複製して使う。

**設定（Ladder の定義と版・在籍者と Reviewer・採用枠）と、候補者の選考の段階はシートに置かない**。
設定は board の設定の画面に、選考の段階は採用のタブに置く。

**値はセルの番地ではなく、見出しの文字で読む。** 行や列を足しても、読み込まれる値は変わらない。
見出しの文字を書き換えると、その値は読まれなくなる。

## 候補者

Drive のルートフォルダの `candidates/` に、1人につき1ファイルを置く。ファイル名は問わない。
シートは「候補者」と「面接」と、面接1回につき1枚の「面接1」「面接2」… である。

### シート「候補者」

A 列に見出し、B 列に値を置く。

| 見出し | 値 |
|---|---|
| 氏名 | 表示に使う名前 |
| メール | 候補者を見分けるキー。同じメールのファイルが2つあると、更新日時の新しいほうを読む |
| 応募枠 | 設定の採用枠のどれか |
| 版 | 面接の判定が使う Ladder の版（例：v1） |
| 応募日 | 日付 |
| 経路 | 自由記述（求人媒体・紹介・採用サイトなど） |

### シート「面接」

1行目が見出しで、面接1回につき1行を足していく。

| 回 | 日付 | 面接官 | 所見 |
|---|---|---|---|

- 回は 1, 2, … の番号で、判定を書くシート「面接1」「面接2」… の番号と合わせる
- 面接官には面接官のメールを書く

### シート「面接1」「面接2」…

形は評価のシート「評価」と同じで、1行に細目1つを置く。2回目からは「面接1」を複製して名前を変える。

| 軸 | 段階 | 細目 | 判定文 | 判定 | 根拠 |
|---|---|---|---|---|---|

- 面接では Ladder の細目をすべて判定する。その面接で聞かなかった細目は空欄のまま残し、聞いたが判定の材料が無かった細目は未観測にする
- 根拠には、聞き取ったことを書く。何を聞くかは [hiring.md](../../ladder/docs/hiring.md) にある

候補者の軸の段階は、細目ごとに判定の入っている最も新しい面接の判定を使い、評価と同じ決め方（下の「評価」）で決める。
どの面接でも聞いていない細目は空欄として扱うので、その軸は段階がまだ決まらない。採用のタブでは、
段階の決まらない軸と未観測の軸を、次の面接で聞くこととして出す。

## 評価

Drive のルートフォルダの `reviews/<期>/` に、評価される人1人につき1ファイルを置く（例：`reviews/2026-H2/emma-hughes`）。
シートは「対象」と「評価」の2枚である。

### シート「対象」

A 列に見出し、B 列に値を置く。

| 見出し | 値 |
|---|---|
| メール | 評価される人のメール。設定の在籍者のメールと同じにする |
| 期 | 評価の期（例：2026-H2） |
| 版 | この評価が使う Ladder の版（例：v1） |
| Reviewer | 評価する担当のメール |

### シート「評価」

1行に細目1つを置く。細目は、シート「対象」の版にあるものを使う。L1 の細目は置かない。L1 は下限で、判定しない。

| 軸 | 段階 | 細目 | 判定文 | 判定 | 根拠 |
|---|---|---|---|---|---|

- 判定には ○・×・未観測のどれかを書く。空欄はまだ判定していないことを表す
- 根拠には判定に使った成果物や記録を書く

判定の値で、軸の段階は次のように決まる。L2 から順に見ていく。

- マスの細目がすべて ○ なら、その段階に届く
- × のある段階で止まり、その1つ下が軸の段階になる。L2 で止まれば L1 である。上の段階は判定しなくてよい
- 未観測のある段階で止まり、その1つ下が軸の段階になる。L2 で止まったときだけは、軸を未観測とする
- 空欄が残っている段階では、軸の段階はまだ決まらない

本人の段階は [ladder.md](../../ladder/docs/ladder.md#段階) の決め方に従う。A か B が未観測のとき、またはまだ決まっていないときは、本人の段階も決まらない。
