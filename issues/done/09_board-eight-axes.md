### Issue 08 との関係（必ず読む）
Board のテストは実物の `ladder/docs/ladder.md` を読む。Issue 08 は ladder.md を8軸にするので、08 だけでも 09 だけでも board の CI は落ちる。そのため2本を1本の PR にまとめる。

- 実装は main から始めてよい。Issue 08 のブランチにコミットが出たら（親セッション mgmt-kit-3c が知らせる）、その上に載せ直してテストを流す
- Issue 08 は push も PR もせず、コミットで止まっている。PR はこの Issue の実行者が、08 と 09 のコミットを含めて1本で出す。08 と 09 の両方の Issue ファイルを `done/` へ閉じる
- Issue 08 の ladder.md は、各軸の判定文の節の見出しを「## 軸名」（記号なし）で書き、節の並びは軸の順、表は「| L1 | 判定文 | 読むもの |」の3列で L1〜L5 の5行になる。`from_ladder_md` はこの見出しの軸名から上の仮定の記号へ対応させる
