### 判定文を書く規則

今の `ladder.md` と `adapt.md` の「書き足すときの規則」に従う。要点は次のとおり。

- 判定文には、リポジトリの何を開けば真偽が分かるかを書き、「読むもの」の列を埋める。抽象語で書かない
- L2 は型が強制するものだけで書く。sdlc-kit が強制しているのは秘密情報（`units/secret-guard`）と設計判断の記録（`JUDGE.md`）までである。データと運用の L2 を型で保証できないなら、ドメイン理解と同じく「L2 の時点で保証から外れる、型の側の欠落」と本文に書く
- L5 は到達点として書く

### 書き換える文書
- `scoring.md`・`hiring.md`・`personas.md`：軸の呼び方を名前に揃え、新しい軸をどう扱うかを足す。ペルソナに新しい軸の段階を足すかどうかは、ペルソナの役目（どの軸がどれだけ足りないかを示す例）に照らして決める
- `adapt.md`：判定文が指す置き場の読み替え表に、新しい判定文が名指しする置き場を足す
- `ladder-score` の skill と採点表のテンプレート：8軸に揃える
- `slides.html`：8軸に揃え、PNG を作り直す
